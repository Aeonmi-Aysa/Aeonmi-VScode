# Home

Welcome to the **Aeonmi.a Quantum Glyph Programming Language** VS Code Extension! This extension is designed to facilitate the development and debugging of applications written in the Quantum Glyph programming language. With a range of powerful features, it enhances the coding experience by providing syntax highlighting, code suggestions, and integrated debugging support.

## Features
- **Syntax Highlighting**: Enjoy improved readability with syntax highlighting tailored for Quantum Glyph.
- **Code Suggestions**: Get real-time code suggestions to speed up your development.
- **Integrated Debugging**: Debug your Quantum Glyph applications directly from VS Code.

## Getting Started
To get started with the Aeonmi.a Quantum Glyph Extension, follow these steps:
1. Install the extension from the VS Code marketplace.
2. Open a Quantum Glyph file in VS Code.
3. Explore the features and enhance your development workflow!
