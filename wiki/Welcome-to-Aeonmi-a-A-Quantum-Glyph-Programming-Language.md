## 🚀 Quick Start

### Installation (Developer)

1. **Manual Installation**:
   - Copy the `vscode-aeonmi/` folder into `%USERPROFILE%\.vscode\extensions\aeonmi-0.1.0\`
   - Reload VS Code

2. **Via VSIX Package**:
   ```powershell
   npm install -g @vscode/vsce
   cd vscode-aeonmi
   vsce package
   code --install-extension aeonmi-0.1.0.vsix
   ```
