# Aeonmi for VS Code — Wiki

Welcome to the wiki for the **Aeonmi VS Code extension**.

Aeonmi is an experimental symbolic programming language exploring AI-native execution, glyph-based syntax, and quantum-style composition. This extension brings Aeonmi language support to Visual Studio Code.

## Quick Start

1. Install the extension from the VS Code Marketplace (search **Aeonmi**).
2. Open or create a file with the `.ai` extension.
3. Syntax highlighting and snippets activate automatically.

```aeonmi
# Hello, Aeonmi
bell ← ⧉0.707‥0‥0‥0.707⧉
ψ ↦ bell ⊗ bell
```
