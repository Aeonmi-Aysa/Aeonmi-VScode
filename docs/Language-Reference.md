# Language Reference

A reference guide to the Aeonmi language syntax as supported by this VS Code extension.

For the full Aeonmi language specification, see the [aeonmi.ai repository](https://github.com/Aeonmi-Aysa/aeonmi.ai).

---

## Overview

Aeonmi is a symbolic programming language designed around a compact **glyph algebra**. Its syntax emphasizes:

- **Symbolic density** — a single glyph can express a complex data operation
- **Composition** — programs are built by composing small symbolic units
- **AI-native structure** — the language is designed to be parsed and generated by AI systems

## Glyph Primitives

Aeonmi's core operators are Unicode glyphs.

| Glyph | Name             | Description                                                   |
|-------|------------------|---------------------------------------------------------------|
| `⧉`   | Array Genesis    | Opens and closes a symbolic array: `⧉ val1 ‥ val2 ⧉`         |
| `⟨⟩`  | Slice / Index    | Access a sub-array or element: `arr⟨0⟩`                      |
| `…`   | Spread           | Expand or distribute a structure: `…arr`                      |
| `⊗`   | Tensor Product   | Compose two structures: `a ⊗ b`                               |
| `↦`   | Binding          | Bind a name to an expression: `name ↦ expression`             |
| `←`   | Assignment       | Assign a value to a name: `name ← value`                      |
| `‥`   | Separator        | Separate elements inside an array genesis                     |

## Variables and Binding

```aeonmi
# Assignment
x ← 42

# Symbolic binding
ψ ↦ x ⊗ y
```

---

## Arrays

Arrays are constructed using the **Array Genesis** glyph `⧉`:

```aeonmi
# A simple array of 4 values
arr ← ⧉ 1 ‥ 2 ‥ 3 ‥ 4 ⧉

# Access element at index 0
first ← arr⟨0⟩
```

---

## Spread

The spread operator `…` distributes a structure:

```aeonmi
flat ← … arr
```

---

## Tensor Product

Compose two symbolic structures with `⊗`:

```aeonmi
bell ← ⧉ 0.707 ‥ 0 ‥ 0 ‥ 0.707 ⧉
ψ ↦ bell ⊗ bell
```

## QUBE Files

QUBE (Quality-Uncertainty Balanced Evolution) is Aeonmi's symbolic quantum-style execution layer.

A `.qube` file can express:

- **State declarations** — define quantum-like states
- **Gate application** — apply symbolic transformations
- **Tensor composition** — compose states
- **Collapse / measurement** — collapse symbolic states
- **Assertions** — verify expected symbolic outcomes

Example:

```qube
# Define a qubit
|0⟩ ← ⧉ 1 ‥ 0 ⧉
|1⟩ ← ⧉ 0 ‥ 1 ⧉

# Superposition via tensor product
|+⟩ ↦ |0⟩ ⊗ |1⟩
```
